# `.github`: NoiXdev org profile

The meta repository of the **NoiXdev** GitHub organisation. GitHub picks it up automatically:

- [`profile/README.md`](profile/README.md) is the page shown on [github.com/NoiXdev](https://github.com/NoiXdev).
- [`assets/brand/`](assets/brand) holds the current logo files used there: the X, the wordmark for light and dark backgrounds, the avatar and the GitHub social banner.
- [`assets/logo/`](assets/logo) holds the older logo files and the personal wordmarks; they stay for links that still point at them.

All brand files, in every size, are on [noix.dev/en/brand](https://www.noix.dev/en/brand) and are generated by `npm run brand` in the [noix.dev](https://github.com/NoiXdev/noix.dev) repository. Copy new versions from there.

When the project list changes on noix.dev, update the tables in `profile/README.md` too: same taglines, same four areas.
